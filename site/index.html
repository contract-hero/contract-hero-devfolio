Agentic Community College

A course runtime for Claude Code, built by someone who used to run a classroom.

ACC is a Claude Code plugin. It turns a session into a tutor that walks a learner through a coding lesson one section at a time. Each lesson starts from a reference implementation, states one key moment per section, and ends every section with a real test gate. The learner either writes the code or watches the agent write it, and either way nothing advances until the tests pass.

The framework ships an MCP server, a conductor agent, and authoring skills. Courses are separate plugins with only content in them: lesson manifests, section prompts, validation commands, and declarative preflight probes that check the environment and can repair it. Write a course for any language or stack; ACC does not care what it is teaching.

I built it because I taught for four years and wanted to know which parts of good teaching an agent can hold: pacing, one idea at a time, checking before moving on. It is a personal project. It has no user numbers to show, and I am not going to invent any. What it has is two complete courses that run on it, and a third on the way.

sui-pilot

A Sui Move plugin for Claude Code. You can be running it in under a minute.

sui-pilot gives Claude Code a working knowledge of Sui Move: an LSP-backed MCP server for diagnostics, hover, references and rename; bundled documentation for Sui, Walrus, Seal, the TypeScript SDK and the Move Book; skills for code quality and security review; and formal specifications checked with the Sui Prover.

It is the tool I wanted next to me while teaching Move to people who had never seen it. The DeepBook course above requires it, which is the clearest sign of how the two projects fit together.

Designing a builder program with no budget

Builder Growth Champions, Sui Foundation, 2026. Design work only.

The brief was to grow serious builders in the ecosystem without a grant budget. The design unbundles what a grant actually buys, line item by line item, and maps each one to a non-cash asset the ecosystem already holds: engineering time, distribution, introductions, infrastructure credits, review. Champions earn access to those assets by shipping, and the playbook tells a regional lead how to run the loop.

The program was cancelled in the August 2026 reorganisation before its first cohort. There are no outcomes to report. What exists is the pitch document and the operating playbook, which I am sharing as an example of how I design a learning program from constraints.
