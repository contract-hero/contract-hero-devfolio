macOS app · free download · Apple Silicon

Manage the files your agents produce.

And organize all your pies-in-the-sky. skypies opens local HTML and Markdown in a native window with tabs, live reload and a skypies:// URL scheme. It shares files between devices without uploading them to a file-hosting service.

Download for Mac Install steps

Current download: v0.1.3 for Apple Silicon Macs, macOS 11 or later. Not notarized; first launch needs your approval.

Install

One download for Apple Silicon Macs (M1 or later) with macOS 11 or later. Intel Macs are not supported.

Download and install

  1. Download the disk image.

    Download for Mac

    Apple Silicon (M1 or later). macOS 11 or later.

  2. Open skypies.dmg. A window with skypies and the Applications folder opens.

  3. Drag skypies to the Applications folder. Then eject the disk image.

First launch

  1. Open skypies from Applications. macOS tells you that it cannot verify the app. Click Done.

  2. Open System Settings → Privacy & Security.

  3. Scroll to Security. Find the message about skypies and click Open Anyway.

  4. Confirm the next prompt and authenticate if asked. skypies opens.

You do this one time. After that, skypies opens normally. The Open Anyway button shows for about one hour after you try to open the app. On macOS 12 and earlier, use System Preferences → Security & Privacy → General.

Gatekeeper. skypies has an ad-hoc signature. Apple does not notarize it. Because of this, macOS blocks the first launch. On macOS 15 and later, right-click → Open does not remove the block. Use Open Anyway in Privacy & Security. See Apple’s instructions.

What you get

These features and shortcuts describe the public Mac v0.1.3 download. It provides a workspace browser, pies, and a reader for your files.

tabs

Browser-style tabs

Each tab keeps its own back and forward history. Drag tabs to reorder. Middle-click closes. The context menu has Close Others and Close to the Right.

live reload

Files reload when they change

Edit an artifact, or let an agent regenerate it, and the open tab updates in place with its scroll position kept. Deleted files show a notice and come back when re-created.

deep links

skypies://open?path=…

Any tool can open a file in skypies with one URL. The app comes to the front. If the file is already open, its tab is focused instead of duplicated. skypies://reveal highlights a file in the tree.

reader mode

Only the document

⇧⌘F hides the sidebar and the toolbar. Tabs and the document stay. Esc brings the chrome back.

quick open

Fuzzy search over the workspace

⌘P opens a palette that matches any file in the workspace by subsequence. The index refreshes when files change on disk.

rendering

HTML, Markdown, code, images

HTML renders in a sandboxed iframe with full CSS, JS and SVG. Markdown gets code highlighting, Mermaid diagrams and KaTeX math. The theme follows the macOS appearance.

Claude Code and Codex plugin

The app bundles skypies-mcp. The plugin gives Claude Code and Codex access to that server and an artifact-links skill. You install the Mac app once; the plugin uses its server and can launch the app when needed.

Install the app first. For Claude Code, run:

claude plugin marketplace add contract-hero/plugin-marketplace
claude plugin install skypies@contract-hero

For Codex CLI 0.153 or later:

codex plugin marketplace add contract-hero/plugin-marketplace
codex plugin add skypies@contract-hero

Start a new session after installing. Both hosts can use the MCP tools to create device links, add artifacts to pies and read feedback, subject to their permissions. Claude Code also has automatic pairing and feedback hooks. See the setup guide for host-specific details.

The Stop hook that checks for missing or hand-written links requires skypies 0.1.3 or later; it is not available with the current 0.1.2 download.

Pairing and Beam

Both routes are peer-to-peer: a direct, end-to-end encrypted QUIC connection over iroh, with an encrypted relay as fallback. No account or hosted file storage is required. Networking starts when you share, pair or open a remote link. After pairing, Listen at launch can keep the app ready to accept your devices as soon as it opens.

Your own devices: pair once

  1. Settings → Devices → Pair a device… shows an invite as a link and a QR code.
  2. Open it on the other device. Both screens show the same six words.
  3. Confirm the words match on both screens. The devices are paired.
  4. Share ▾ → Copy link for my devices gives a device link that identifies this Mac. Open it on a paired device and the file opens there, pulled from this Mac.

Nothing is copied ahead of time and nothing is queued. Both machines need skypies running. A paired device can open any file you share with it by link.

Anyone else: Beam

  1. Share ▾ → Beam to anyone…, or right-click a file → Beam to Anyone…. The app mints a skypies://receive?ticket=… link.
  2. Send the link over any channel. The link is a capability, not the content.
  3. On the other Mac the link raises skypies and shows a confirm dialog with the file name, its size and your identity fingerprint. Nothing transfers until they accept.
  4. The file lands in the app's received/ folder and opens with a beamed badge. Received HTML renders in a hardened, origin-isolated iframe.

The offer is served while the app runs, 24 hours by default. The ⚡ indicator lists active beams and has a Stop that prevents new transfers. It does not remove copies already received.
