macOS app · free download · Apple Silicon + Intel

Manage the files your agents produce.

And organize all your pies-in-the-sky. skypies opens local HTML and Markdown in a native window with tabs, live reload and a skypies:// URL scheme. It sends a file to your other devices without a server.

Download for Mac Install steps

Universal app for Apple Silicon and Intel. Needs macOS 11 or later. The app is not notarized, so you allow it once on first launch.

Install

One download. The same app runs on Apple Silicon and Intel Macs with macOS 11 or later.

Download and install

  1. Download the disk image.

    Download for Mac

    Universal: Apple Silicon and Intel. macOS 11 or later.

  2. Open skypies-universal.dmg. A window with skypies and the Applications folder opens.

  3. Drag skypies to the Applications folder. Then eject the disk image.

First launch

  1. Open skypies from Applications. macOS tells you that it cannot verify the app. Click Done.

  2. Open System Settings → Privacy & Security.

  3. Scroll to Security. Find the message about skypies and click Open Anyway.

  4. Click Open Anyway again, then enter your password or use Touch ID. skypies opens.

You do this one time. After that, skypies opens normally. The Open Anyway button shows for about one hour after you try to open the app. On macOS 12 and earlier, use System Preferences → Security & Privacy → General.

Gatekeeper. skypies has an ad-hoc signature. Apple does not notarize it. Because of this, macOS blocks the first launch. On macOS 15 and later, right-click → Open does not remove the block. Use Open Anyway in Privacy & Security.

What you get

A browser-shaped window over a read-only view of one workspace folder.

tabs

Browser-style tabs

Each tab keeps its own back and forward history. Drag tabs to reorder. Middle-click closes. The context menu has Close Others and Close to the Right.

live reload

Files reload when they change

Edit an artifact, or let an agent regenerate it, and the open tab updates in place with its scroll position kept. Deleted files show a notice and come back when re-created.

deep links

skypies://open?path=…

Any tool can open a file in skypies with one URL. The app comes to the front. If the file is already open, its tab is focused instead of duplicated. skypies://reveal highlights a file in the tree.

reader mode

Only the document

⇧⌘F hides the sidebar and the toolbar. Tabs and the document stay. Esc brings the chrome back.

quick open

Fuzzy search over the workspace

⌘P opens a palette that matches any file in the workspace by subsequence. The index refreshes when files change on disk.

rendering

HTML, Markdown, code, images

HTML renders in a sandboxed iframe with full CSS, JS and SVG. Markdown gets code highlighting, Mermaid diagrams and KaTeX math. The theme follows the macOS appearance.

Claude Code plugin

The app includes an MCP server, skypies-mcp. The Claude Code plugin is a companion to the app. It finds the installed app and runs this server. It downloads nothing.

Install the app first. Then run:

claude plugin marketplace add contract-hero/plugin-marketplace
claude plugin install skypies@contract-hero

From a Claude Code session, the plugin makes a link for your paired devices, beams an artifact, pairs a device and lists paired devices. See the skypies-plugin README.

Pairing and Beam

Both routes are peer-to-peer: a direct, end-to-end encrypted QUIC connection over iroh, with an encrypted relay as fallback. No account, no upload. The app opens no sockets until you share or pair something.

Your own devices: pair once

  1. Settings → Devices → Pair a device… shows an invite as a link and a QR code.
  2. Open it on the other device. Both screens show the same six words.
  3. Confirm the words match on both screens. The devices are paired.
  4. Share ▾ → Copy link for my devices gives a skypies://open?path=…&from=… link. Open it on a paired device and the file opens there, pulled from this Mac.

Nothing is copied ahead of time and nothing is queued. Both machines need skypies running. A paired device can open any file you share with it by link.

Anyone else: Beam

  1. Share ▾ → Beam to anyone…, or right-click a file → Beam to Anyone…. The app mints a skypies://receive?ticket=… link.
  2. Send the link over any channel. The link is a capability, not the content.
  3. On the other Mac the link raises skypies and shows a confirm dialog with the file name, its size and your identity fingerprint. Nothing transfers until they accept.
  4. The file lands in the app's received/ folder and opens with a beamed badge. Received HTML renders in a hardened, origin-isolated iframe.

The offer is served while the app runs, 24 hours by default. The ⚡ indicator lists active beams and has a Stop that revokes a link at once.
