01 / What it is

A little room
for what you make.

Agentic tools write HTML reports, audits, plans, explainers and Markdown notes to disk. skypies opens each one in one action, renders it at full browser fidelity, and keeps the view on the file as it changes.

Your workspace, with a place to read.

02 / Four properties

From the first link
to the next device.

01

Deep-link
addressable.

The skypies://open?path=… URL scheme lets any agent, script or Markdown link open a specific local file in the app, with an optional line target.

02

Live on
local files.

A file open in a tab reloads when it changes on disk and keeps its scroll position. Watch an agent rewrite a report in place.

03

A tree made
for reading.

Tabs, per-tab history, quick open, bookmarks and recents over a directory. The app reads and reveals files. It never creates, renames or deletes your workspace files.

04

Peer to peer.
Hand to hand.

Pair your devices once; a link pulls the file from the machine it lives on. For anyone else, Beam serves one artifact behind a link: direct, end-to-end encrypted, no upload.

03 / Pies · the next app window

Every project is a pie.
Every pie is a cloud.

In the planned sky view, a pie collects the artifacts of one project. Its wedges show what it holds by file kind: HTML, Markdown, code, images, data. Each pie is drawn from rows of HTML source text, the same pattern as the app icon.

  • Hover to see its label and the count per kind.
  • Turn with a drag or the arrow keys to bring each kind to the front.
  • Open the plate: the list of files, ready to read.

05 / Plugin + MCP

Claude Code talks
to the running app.

skypies-mcp is a stdio MCP server and a thin client of the app. From a Claude Code session it can mint a device link, beam an artifact, pair a device and list paired devices. The plugin bundles the server, a pairing hook and an artifact-links skill, so each session can end with a clickable skypies:// link.

Install from Claude Code

/plugin marketplace add contract-hero/plugin-marketplace
/plugin install skypies@contract-hero

Deep links

skypies://open?path=… opens a file. skypies://reveal?path=… highlights it in the tree. &line=N supplies a line target.

CLI

skypies open, skypies reveal, skypies beam and skypies receive hand an intent to the app. Nothing is staged or fetched without your click.

Feedback loop

Comments you leave on an artifact in the app are readable from the session that wrote it, and can be marked as resolved from there.
