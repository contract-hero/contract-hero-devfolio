01 / What it is

A little room
for what you make.

Agentic tools write HTML reports, audits, plans, explainers and Markdown notes to disk. skypies opens each one in one action, renders it at full browser fidelity, and keeps the view on the file as it changes.

Your workspace, with a place to read.

02 / From folder to feedback

A place for the work.
A way to keep it moving.

01

File by topic.

Let jev, by TypeSafe, sort your working folder into pies. It is opt-in, uses your own key, and sends file text to TypeSafe only when you enable sorting.

02

Read anywhere.

Pair your other Macs once, and soon your iPhone. Open the same documents from the machine they live on. The iPhone companion, in development, will show your Mac’s pies, read-only.

03

Beam a file.

Anyone with skypies can send you a file with one link. Peer to peer, end-to-end encrypted, no login, no file server to set up, nothing uploaded to hosted storage.

04

Leave a comment.

Comment on lines, HTML elements or spots on images, on the Mac or from a paired device. Your agent can read the feedback and act on it.

05 / Plugin + MCP

Your agent talks
to the Mac app.

The plugin works with Claude Code and Codex. It uses the MCP server bundled with the Mac app to make links for your paired devices, organize artifacts into pies, send Beams and read your feedback. Its artifact-links skill asks the agent to return a clickable link for each document it creates.

Install the Mac app first · Claude Code

claude plugin marketplace add contract-hero/plugin-marketplace
claude plugin install skypies@contract-hero

Codex CLI · 0.153 or later

codex plugin marketplace add contract-hero/plugin-marketplace
codex plugin add skypies@contract-hero

Start a new session after installing. See the plugin setup guide for host-specific hooks and permissions.

Deep links

skypies://open?path=… opens a file. skypies://reveal?path=… locates it in the app. &line=N supplies a line target.

Needs the Mac app

The plugin uses the server inside skypies.app and can launch the app when a tool needs it. Keep the Mac awake and skypies running while another device opens a shared link.

Feedback loop

With the plugin, your agent reads your comments, acts on them and marks them addressed. In Claude Code, the open comments on a file reach the agent as soon as it reads that file.

06 / Get it

One app.
One plugin.

The Mac app is free and closed source. The plugin is open source and connects Claude Code and Codex to the running app.

skypies for MacFor Apple Silicon Macs (M1 or later), macOS 11 or later.↓ skypies-pluginThe Claude Code and Codex companion: device links, pies and artifact feedback.↗

The plugin is open source under Apache-2.0. Skypies does not collect reading analytics. Sharing and comment sync use encrypted peer-to-peer connections, with an encrypted relay when needed. HTML artifacts can make their own web requests. jev sorting is the one feature that sends file text off the Mac, to TypeSafe, and only after you turn it on.

07 / The name

Why skypies?

“Pie in the sky” is an English expression for a pleasant idea or promise that is unlikely to come true: something you hope for but may never get. The image is of a delicious pie floating in the sky, out of reach.

Every agent run promises something. skypies is a place to organize those pies in the sky while you navigate agentic software engineering. The phrase comes from Joe Hill, a Swedish-born American organizer with the IWW, the “Wobblies”: his 1911 song “The Preacher and the Slave”, first printed in the Little Red Songbook, parodied “In the Sweet By-and-By” and the Salvation Army’s promise of a reward after death for hungry workers. The people doing the work deserve their pie now. Keep yours within reach, here, on your own machines.
