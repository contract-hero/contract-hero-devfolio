One receiver, many tokens

I authored the Fungible Token Switchboard: a single receiver capability that can route deposits to different token vaults. The contribution includes the contract, tests, documentation, and follow-up improvements.

It is part of the Flow fungible-token standard and is deployed on mainnet.

Metadata that applications can read

I authored the Fungible Tokens Metadata proposal and the FungibleTokenMetadataViews contract, and implemented the views on ExampleToken. This gives applications a common interface for reading token metadata.

Adoption, measured

In a check on 25 September 2026, FungibleTokenMetadataViews ranked #6 by direct imports among the Flow mainnet contracts tracked by Contract Browser, with 431 dependent contracts.

This is a dated snapshot of contracts importing the metadata interface. It does not count users or transactions.
